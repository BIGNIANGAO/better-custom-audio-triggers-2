# 更好的自定义音频触发 / Better Custom Audio Triggers

**给你的爬塔过程加一点「逢变放曲」的节目效果。**

更好的自定义音频触发是《杀戮尖塔》一代的音频触发 Mod。残血时播放 BGM、打出高伤害时响起一句语音、战斗胜利时来个音效——你可以导入自己的音频，在游戏内决定什么时候播放、播放哪一段，以及什么时候停止。

[Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3830077500) · [反馈问题](https://github.com/BIGNIANGAO/battle-audio/issues)

## 功能

- **按游戏事件播放**：支持血量、伤害、战斗、回合、卡牌操作、资源变化、探索事件和角色特色机制等条件。
- **自定义音频片段**：选择播放起止位置，调整每个音频的音量与原游戏背景音乐的保留比例。
- **概率与随机播放**：为规则设置触发概率，添加多个音频候选，选择完全随机或避免连续重复。
- **控制播放过程**：支持单次、有限循环、无限循环、停止条件及跨房间播放策略。
- **关联规则**：设置前置规则，或在其他规则播放期间暂停当前音频，结束后从原进度恢复。
- **游戏内编辑**：导入音频、搜索条件、试听和编辑都在游戏内完成，有效修改自动保存。
- **多语言界面**：支持游戏提供的 24 种语言，跟随游戏语言设置。

## 安装与使用

适用于《杀戮尖塔》一代 **PC / Windows**。

1. 订阅 [ModTheSpire](https://steamcommunity.com/sharedfiles/filedetails/?id=1605060445)、[BaseMod](https://steamcommunity.com/sharedfiles/filedetails/?id=1605833019) 和 [更好的自定义音频触发](https://steamcommunity.com/sharedfiles/filedetails/?id=3830077500)。
2. 使用 ModTheSpire 启动游戏，启用 BaseMod 和本 Mod。
3. 在主菜单打开 **Mods → 更好的自定义音频触发 → Config**。其他语言下名称会相应变化；爬塔时也可以点击顶部扬声器图标或按 **F10**。
4. 选择已有规则，或新建规则并点击 **添加候选音频**，然后设置触发条件和播放方式。

2.0 将 Mod 本体与音乐包拆分：本体负责规则、播放和包管理，音乐包是独立的可订阅工坊项目。已有 0.4.x 设置会在首次启动时迁移为本地独立音乐包，并保留当前规则、音频和各自开关；新安装不会把音乐文件打进 Mod 本体。

发布音乐包时，先右键本地音乐包并选择 **导出供创意工坊发布**，再点击左侧的 **发布音乐包**。向导会让你选择导出快照、填写名称和曲目、选择封面、预览内容与可见性，并在最终确认后通过 Steam 发布。默认可见性为私有。已发布项目可通过 ID 或链接验证账号归属后关联，后续更新使用同一项目。Steam 协议或安全确认需由玩家完成。发布向导和音乐包操作界面跟随游戏语言，支持游戏提供的 24 种语言。

更改游戏语言后，请按游戏提示重启。升级时避免同时启用旧的手动安装包和工坊版。包格式、迁移和发布行为以 `docs/ARCHITECTURE.md` 与 `docs/BUILDING.md` 为准。
## 触发条件示例

- **战斗与血量**：战斗开始或胜利、玩家死亡、受到伤害、血量达到阈值、击杀敌人。
- **卡牌与资源**：打牌、抽牌、弃牌、消耗卡牌、获得能量或格挡、使用药水、获得遗物。
- **探索与奖励**：篝火休息、锻造、开宝箱、商店购买或删牌、战斗奖励选牌。
- **角色机制**：铁甲战士的力量与消耗、静默猎手的小刀与毒、故障机器人的充能球与集中、观者的姿态与占卜。

具体条件和筛选项可在设置界面中查看；其他 Mod 新增的机制不保证能够识别。

## 设置与备份

本地音乐包和个人设置保存在游戏目录的 `BetterCustomAudioTriggers` 文件夹中。把完整音乐包文件夹放进其中的 `music-packs`，重启游戏即可识别；每个包包含自己的 `music-pack.json` 和音频。`settings.json` 保存个人开关，根列表规则单独保存在 `root-rules.json`。订阅音乐包仍直接使用 Steam 工坊目录，游戏内对订阅包的编辑也写入该目录；Steam 更新可能覆盖修改，需要保留时请先右键复制为本地音乐包。首次升级会复制旧 `.battleaudio` 数据并保留原目录；备份时复制游戏目录中的 `BetterCustomAudioTriggers`。

## 开发与构建

项目使用 Java，编译目标为 Java 8，依赖本机安装的 Slay the Spire、ModTheSpire 和 BaseMod。

从源码构建需要准备本机游戏依赖；默认构建导入音频时需要可用的本地 FFmpeg。具体环境、构建参数和测试方法见[构建与测试说明](docs/BUILDING.md)，模块划分见[架构说明](docs/ARCHITECTURE.md)。
